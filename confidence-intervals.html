Confidence Interval Lab

Chapter 8 · Use one sample to estimate a population value. Four tabs: what “95% confident” means, what changes the width, z versus t, and a calculator for every interval in the chapter.

All numbers are computed in the page. Simulations use random draws, so results change a little each time. Table values (1.96, 2.33, 2.575) can differ from Excel in the last digit.
